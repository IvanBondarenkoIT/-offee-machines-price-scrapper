# Анализ товаров, найденных скрапером, но не найденных через WooCommerce API

## Проблема

Есть товары, которые найдены через скрапер (столбец `DIM_KAVA`), но не найдены через WooCommerce API (столбец `DIM_KAVA_STOCK`).

**Примеры:**
1. `ECAM22.110.SB` - скрапер нашел (1999.00 \ 1399.00), но API не нашел
2. `F86/0-100EU` - скрапер нашел (5999.00), но API не нашел
3. `KBD2001` - скрапер нашел (289.00), но API не нашел

## Результаты анализа

### 1. ECAM22.110.SB

**Статус:** ✅ ТОВАР ЕСТЬ В WOOCOMMERCE!

- **Название в WooCommerce:** "DeLonghi Magnifica S (ECAM22.110.SB)"
- **Модель извлечена:** `ECAM22.110.SB` ✅
- **Нормализованная модель:** `ECAM22110SB`
- **Stock:** 0, **Price:** 1399.0

**Проблема:** Товар найден в WooCommerce, но не сопоставлен при построении таблицы.

**Возможные причины:**
- Проблема с нормализацией модели при сопоставлении
- Проблема с пробелами в названии модели
- Проблема с регистром букв (SB vs sb)

### 2. F86/0-100EU

**Статус:** ❌ ТОВАР НЕ НАЙДЕН ПО ТОЧНОЙ МОДЕЛИ

- **В скрапере:** модель `F86/0-100EU`
- **В WooCommerce:** найдено похожих товаров:
  - "Melitta Barista Smart TS F86/0-100" → модель `F86/0-100` (БЕЗ "EU")
  - "Melitta Barista Smart TS Black F85/0-102EU" → модель `F85/0-102EU`

**Проблема:** 
- В WooCommerce модель извлекается как `F86/0-100` (без "EU")
- В скрапере модель `F86/0-100EU` (с "EU")
- Нормализация:
  - WooCommerce: `F860100`
  - Скрапер: `F860100EU`
  - **НЕ СОВПАДАЮТ!** ❌

**Причина:** Разные форматы модели в названиях товаров.

### 3. KBD2001

**Статус:** ❌ ТОВАР НЕ НАЙДЕН ПО ТОЧНОЙ МОДЕЛИ

- **В скрапере:** модель `KBD2001`
- **В WooCommerce:** найден товар "DeLonghi KBD2001.BK" → модель `KBD2001.BK` (С суффиксом .BK)

**Проблема:**
- В WooCommerce модель извлекается с суффиксом цвета `.BK`
- В инвентаре модель без суффикса `KBD2001`
- При сопоставлении они не совпадают

**Причина:** Модель в WooCommerce включает суффикс цвета, а в инвентаре - нет.

## Выводы

### Основные проблемы:

1. **Проблема нормализации моделей:**
   - Разные форматы моделей (с/без суффиксов, с/без "EU")
   - Нормализация не учитывает эти различия

2. **Проблема извлечения моделей:**
   - В WooCommerce модель может извлекаться с дополнительными суффиксами (цвет, регион)
   - В инвентаре модель может быть без суффиксов

3. **Проблема сопоставления:**
   - Товары есть в WooCommerce, но не сопоставляются из-за различий в форматах моделей

## Рекомендации по решению

### Решение 1: Улучшить нормализацию моделей

**Проблема:** Нормализация не учитывает суффиксы (EU, цвета, и т.д.)

**Решение:**
- Модифицировать `ModelExtractor.normalize_for_matching()` для удаления общих суффиксов:
  - Удалять суффиксы регионов: `EU`, `US`, `RU`, и т.д.
  - Удалять суффиксы цветов: `.BK`, `.W`, `.R`, `.B`, `.SB`, и т.д.
  - Удалять суффиксы только если они в конце модели

**Пример:**
```python
# Было:
F86/0-100EU → F860100EU
F86/0-100 → F860100
# Не совпадают!

# Должно быть:
F86/0-100EU → F860100 (удалить EU)
F86/0-100 → F860100
# Совпадают!
```

### Решение 2: Fuzzy matching по части модели

**Проблема:** Точное совпадение не работает для моделей с разными суффиксами

**Решение:**
- Добавить fuzzy matching, который сравнивает базовую часть модели
- Например: `KBD2001` и `KBD2001.BK` должны совпадать

**Пример:**
```python
# Базовая модель: KBD2001
# Варианты: KBD2001, KBD2001.BK, KBD2001.W
# Все должны совпадать с базовой моделью
```

### Решение 3: Дополнительный поиск по названию

**Проблема:** Если модель не извлекается или не совпадает, товар теряется

**Решение:**
- Если точное совпадение модели не найдено, искать по названию товара
- Использовать fuzzy string matching для поиска похожих названий

**Пример:**
```python
# Если модель F86/0-100EU не найдена
# Искать по названию: "Barista Smart TS SST F86"
# Найти: "Melitta Barista Smart TS F86/0-100"
```

### Решение 4: Улучшить извлечение моделей из WooCommerce

**Проблема:** 97 товаров в WooCommerce без извлеченной модели

**Решение:**
- Улучшить паттерны в `ModelExtractor` для лучшего распознавания моделей
- Добавить специальные правила для Melitta (F86/0-100 vs F86/0-100EU)
- Добавить правила для удаления суффиксов при извлечении

## Приоритет исправлений
