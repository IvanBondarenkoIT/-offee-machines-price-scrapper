# ☕ Coffee Machines Price Scrapper - ФИНАЛИЗИРОВАННАЯ ВЕРСИЯ

## 🎯 Готовый к использованию проект

Этот проект полностью настроен и протестирован для мониторинга цен на кофемашины с конкурентных сайтов.

---

## 📦 Что есть в проекте

### ✅ Рабочие скраперы (6 сайтов):
- **ALTA** - 80 товаров
- **KONTAKT** - 24 товара  
- **ELITE** - 33 товара
- **DIM_KAVA** - 41 товар (ваш сайт)
- **COFFEEHUB** - 49 товаров (с правильными скидками!)
- **COFFEEPIN** - 136 товаров

**ИТОГО: ~363 товара**

### 📁 Заархивировано:
- `web_app_ARCHIVE.zip` - веб-приложение Flask
- `portable_build_ARCHIVE.zip` - портативная версия с GUI (290 MB)
- `web_uploader_ARCHIVE.zip` - утилита загрузки данных

---

## 🚀 Как использовать

### Вариант 1: Батник (рекомендуется)
```bash
RUN_FULL_CYCLE_AND_UPLOAD.bat
```

### Вариант 2: Python
```bash
python run_full_cycle.py
```

### Результат:
```
data/output/price_comparison_YYYYMMDD_HHMMSS.xlsx
```

---

## 📊 Формат цен в Excel

**Цены со скидками:**
```
3359.00 \ 2259.00
  ↑         ↑
старая   финальная
```

**Цены без скидок:**
```
2649.00
   ↑
финальная
```
